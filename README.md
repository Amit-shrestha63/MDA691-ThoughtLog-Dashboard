# MDA691 Thought Log Dashboard

Interactive prototype for **Real-Time Data with Agentic AI for Industrial Predictive Maintenance (PdM)** on the runlinc E32W platform.

## Open

Double-click `index.html` or run:

```bash
open /Users/amit/Desktop/MDA691_ThoughtLog_Dashboard/index.html
```

## Panels

- **Live Features** — RMS, peak–peak, crest, temperature, FFT bands
- **RUL Trend** — hours remaining + SHAP drivers
- **Thought Log** — agent reasoning and schema-valid tool calls
- **Alert History** — ISO reflex + agent flags
- **Simulated ERP** — work order / notify / parts actions
- **Status bar** — device, MQTT, agent latency, NFR targets

Suitable as Assignment 2 Figure 5 dashboard prototype / demo screenshot.
